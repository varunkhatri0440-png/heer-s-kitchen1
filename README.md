# Aurelia Haute Kitchenware — Interactive Cinematic Experience

A state-of-the-art interactive web application built with **Next.js 15**, **React 19**, **Tailwind CSS**, and a **Hardware-Accelerated HTML5 Canvas Scrubber Engine**.

## ✨ Features

- **Collection 01: The Aurelia Balloon Whisk Series (`f1`)**: Pinned 60/120fps canvas scrub through 118 high-resolution frames with responsive aspect-ratio cover.
- **Seamless Horizontal Viewport Transition**: Smooth horizontal slide between sections upon completion of sequence.
- **Collection 02: Hydro-Forged 8.5" Damascus Chef's Knife (`f2`)**: Resumed vertical scroll scrubbing through 66 frames with high-speed water splash droplets.
- **Collection 03: Grand Atelier 14-Piece Master Ensemble (`f3`)**: Background element emerging dynamically from the center of the viewport with 117 frames of zero-gravity kinetic utensil equilibrium.
- **Liquid Glass Aesthetics**: Ultra-transparent frosted glassmorphism (`backdrop-filter: blur(40px)`) with specular bevel reflections and glowing rim lights across all overlays.
- **Precision Cursor Hotspots**: Interactive hotspots that open exclusively when hovering the target anchor and close seamlessly on exit.
- **Slide-Out Metallurgical Specs Drawer**: Transparent liquid glass lab view with specifications, pure material breakdowns, and ordering simulator.
- **Zero-Flicker Performance**: Linear interpolation (LERP) physics, GPU pre-decoding (`img.decode()`), and O(1) indexed image buffers.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+

### Installation
```bash
# Clone the repository
git clone https://github.com/varunkhatri0220-collab/heer-s-kitchen.git

# Navigate into project directory
cd heer-s-kitchen

# Install dependencies
npm install

# Run the development server
npm run dev

# Or build for production
npm run build
npm start
```

Open [http://localhost:3000](http://localhost:3000) (or `http://localhost:3001`) with your browser to experience the site.
